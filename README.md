## Контекст

Задача: выгрузить справочники и вакансии из внутренней административной 
панели (Yii2) для последующего анализа.

API не документирован. Все эндпоинты, поля форм и связи между 
справочниками восстановлены по HTML-разметке и поведению интерфейса.

### Что пришлось сделать разведкой

- определить фреймворк (Yii2) и его паттерны (CSRF, pageSize, activeForm);
- найти AJAX-эндпоинты по инлайн-скриптам страниц;
- восстановить связи: vacancy → vacancy_list → category;
- разобраться с сессиями, CSRF и ротацией токена при логине.

### Результат

- `dump.py` — сводная выгрузка 4 справочников (~2700 вакансий, 
  ~450 номенклатур, ~250 организаций, ~30 категорий) с инкрементальным 
  сохранением и атомарной записью JSON;
- `build_dicts.py` — нормализация в связанные словари с обратными 
  индексами и подсчётом «мёртвых» ссылок;
- `build_xlsx.py` — 5 XLSX-выгрузок: по категориям персонала, а также 
  отдельно «для вузов» и «для колледжей».

### Методика

Разведка и разработка велись в паре с ИИ-ассистентом (chat.deepseek.com, 
без API — обычный диалог в браузере). Ассистент помогал:

- разбирать HTML-разметку Yii2-форм и находить селекторы;
- формулировать единый формат JSON-отчёта и логику связей между 
  справочниками;
- вылавливать типовые ошибки (кодировки Windows, Pylance-предупреждения, 
  редиректы и ротация cookie в Yii2).

Все решения — архитектурные, по структуре данных, по фильтрации вакансий 
и по формату выгрузки — принимались вручную, по результатам прогонов 
на живой системе. Ассистент использовался как ускоритель, а не как 
автор проекта.

*Скрипты разовые, привязаны к конкретной системе. Инструкция по запуску 
не приводится — репозиторий служит описанием проделанной работы и 
примером подхода.*
